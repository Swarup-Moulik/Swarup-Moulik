## 🚀 Flagship Projects & Current Focus

*   **[Moksha](https://github.com/Moksha-Lang/moksha)** ![C++20](https://img.shields.io/badge/C%2B%2B-20-00599C?style=flat-square&labelColor=003366) ![LLVM](https://img.shields.io/badge/LLVM-22-26001B?style=flat-square&labelColor=590082) ![MLIR](https://img.shields.io/badge/MLIR-Compiler-F34B7D?style=flat-square&labelColor=990033)  
    Architecting a high-performance, imperative programming language completely from the ground up! The custom compiler toolchain is engineered in modern **C++20**, leveraging **MLIR** for advanced intermediate lowering passes and an **LLVM 22** backend to blast out highly optimized, bare-metal machine code. Packed with powerful features like zero-overhead Automatic Reference Counting (ARC) and native inline assembly support for ultimate control.

*   **[MayaOS](https://github.com/Moksha-Lang/maya)** ![Moksha](https://img.shields.io/badge/Language-Moksha-FF5733?style=flat-square&labelColor=CC3300) ![UEFI](https://img.shields.io/badge/Boot-UEFI-000000?style=flat-square&labelColor=white&labelTextColor=black) ![x86--64](https://img.shields.io/badge/Arch-x86__64-0071C5?style=flat-square&labelColor=00BFFF)  
    Forging a next-generation, UEFI-bootable operating system written entirely natively in Moksha! Pushing the limits of bare-metal engineering with a custom 4-level paging VMM, a robust ATA PIO driver, and a completely bespoke native filesystem (**MayaFS**). Currently pioneering the SMALA (System-Managed Adaptive Layout Architecture) to revolutionize OS-level graphics and dynamic UI rendering.
